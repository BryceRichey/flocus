# Flocus Task Tracking Web App

This web app is built using the following technologies on the client side: React, Redux, Javascript, Tailwind CSS, a PostgreSQL database connection, and Express with Node for the server-side.

Flocus is a work in progress web app that is meant to be both simple and lightweight.
